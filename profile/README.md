# Moin, wir sind Flokani.

**Digitale Werkstatt aus Schleswig.**

Wir bauen Websites, entwickeln Web-Tools und automatisieren Abläufe.
Mit WordPress, Astro, n8n und UiPath entstehen Lösungen, die dir im Alltag Arbeit abnehmen.
Vom ersten Gespräch bis zur Weiterentwicklung hast du mit Nick einen direkten Ansprechpartner.

Auf GitHub teilen wir Werkzeuge und Integrationen aus unserer Projektarbeit.
